HighRiskify Onramp for Odoo 19
================================

HighRiskify Onramp adds a hosted checkout payment provider to Odoo 19 Website and eCommerce checkout flows. It creates Odoo payment transactions, redirects customers to the configured hosted checkout destination, receives callbacks/status notifications, and synchronizes related Odoo transactions, sales orders, quotations, and invoices where applicable.

Configuration
-------------

After installation, open Payment Providers, activate HighRiskify Onramp, and configure the payout wallet address, API domain, hosted checkout domain, branding fields, and operational settings.

External Services
-----------------

The module connects Odoo with HighRiskify integration services and configured checkout/routing services for checkout redirection, transaction reference creation, callback handling, transaction tracking, and status synchronization. Limited transaction/order-related data may be exchanged for these functions.
