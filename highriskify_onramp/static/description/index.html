HighRiskify Onramp

Secure Hosted Onramp Payment Provider for Odoo 17

HighRiskify Onramp allows Odoo eCommerce stores to accept customer payments through a secure hosted HighRiskify checkout flow. The module adds HighRiskify as an Odoo payment provider, redirects customers to the hosted payment page, and updates the related Odoo order after payment confirmation.

Main Features

```

Hosted Checkout

Redirect customers from Odoo checkout to the secure HighRiskify hosted payment page.

Odoo eCommerce Support

Designed for Odoo 17 Website and eCommerce checkout payment flows.

Payment Session Creation

Creates payment sessions for Odoo transactions and sends customers to the hosted checkout.

Callback / IPN Handling

Processes HighRiskify payment callbacks and updates the Odoo payment transaction status.

Order Chatter Logs

Logs payment updates and transaction information in the related Odoo order chatter.

Backend Configuration

Configure API URL, hosted checkout URL, button text, descriptions, branding, and payment settings.

```

How It Works

```

1. Customer Selects HighRiskify Onramp

During Odoo website checkout, the customer selects HighRiskify Onramp as the payment provider.

2. Odoo Creates the Payment Transaction

The module prepares the Odoo payment transaction and creates the related HighRiskify hosted checkout session.

3. Customer Completes Hosted Payment

The customer is redirected to the HighRiskify hosted checkout page to complete the payment securely.

4. Callback Updates Odoo

After payment confirmation, the module processes the callback/IPN and updates the Odoo transaction and order status.

```

Backend Configuration

Store administrators can configure HighRiskify provider settings directly from the Odoo payment provider backend. The module includes settings for API endpoints, hosted checkout URL, button labels, descriptions, branding, and operational payment options.

```
```

Built for Hosted Payment Processing

HighRiskify Onramp keeps the customer payment flow simple by redirecting customers to a hosted checkout page. This helps merchants keep payment handling outside the Odoo checkout screen while still keeping order and payment transaction status updated inside Odoo.

External Service & Data Disclosure

```

This module connects to HighRiskify payment infrastructure and related operational tracking endpoints to create payment sessions, redirect customers to the hosted checkout page, process callbacks, and update payment/order status in Odoo.

Operational payment data may be transmitted to HighRiskify services for payment processing and transaction tracking. This may include transaction reference, order amount, currency, selected payment method, payment status, customer email where available, wallet/payment session information, callback status, transaction identifiers, merchant site information, and timestamps.

Merchants should review and configure the module according to their own privacy, compliance, and payment processing requirements. Privacy Policy: https://highriskify.com/privacy-policy

```

Installation & Support

```

Install the module, update the Odoo Apps list, activate HighRiskify Onramp from Payment Providers, configure your HighRiskify API and checkout settings, and enable the provider for your Odoo website checkout.

For setup help, configuration support, or bug reports, please contact HighRiskify support.

```
