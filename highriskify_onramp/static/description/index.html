HighRiskify Onramp

Crypto Onramp for Odoo - MoonPay, Transak, Ramp, Coinbase Pay, Revolut

HighRiskify Onramp integrates with Odoo Ecommerce, Odoo Website, Odoo Invoicing, and Odoo Subscription applications. It adds hosted checkout, checkout redirection, payment links, multi-provider routing, regional availability support, and transaction status synchronization for fiat-to-crypto, card-to-crypto, bank transfer, and digital asset purchase flows.

How It Works

1. Customer Selects HighRiskify

The customer selects HighRiskify Onramp during the Odoo checkout process.

2. Checkout Session Is Initiated

The module creates transaction references and starts the hosted checkout workflow.

3. Customer Is Redirected

The customer is redirected to the configured checkout destination.

4. Status Updates Are Received

The module receives status notifications and synchronization updates from the checkout workflow.

5. Odoo Records Are Updated

Related transaction, sales order, quotation, and invoice records are updated automatically within Odoo.

Backend Configuration

Configure HighRiskify integration settings directly within Odoo: service endpoints, checkout destinations, display labels, descriptions, branding elements, status synchronization settings, and operational options.

External Service & Data Handling

This module connects Odoo with HighRiskify integration services to support checkout redirection, transaction reference creation, status synchronization, callback handling, transaction tracking, and related operational functionality.

During normal module operation, limited transaction and order-related information may be exchanged with HighRiskify services so the integration can initiate checkout workflows, receive status updates, assist with transaction tracking, and synchronize Odoo records.

Data exchanged may include order references, invoice references, transaction amounts, currency, selected payment method, status information, customer information where available, session identifiers, callback notifications, merchant website information, transaction identifiers, and system-generated timestamps.

Merchants are responsible for reviewing, configuring, and using the module in accordance with their own privacy, compliance, and operational requirements. Privacy Policy: https://highriskify.com/privacy-policy
