HighRiskify POS Crypto
======================

Odoo POS Crypto Payments | Bitcoin, USDC & USDT Gateway

HighRiskify POS Crypto adds cryptocurrency payment support to Odoo Point of Sale. It can be used for POS Crypto, POS Bitcoin, POS USDC, POS USDT, POS Stablecoin, POS Payments, Crypto POS, Bitcoin POS, Stablecoin POS, pos application, pos machine, pos gateway, and in-person Odoo POS crypto payment gateway workflows.

Short Description / Tagline
---------------------------

Accept Bitcoin, USDC, USDT, BTC, BCH, LTC, DOGE, ETH, SOL and stablecoin crypto payments in Odoo POS with QR payments, payment links, Wallet Connect, hosted checkout, non-custodial/self-custody settlement, webhook status sync, and POS crypto gateway support.

Configuration
-------------

1. Install the module.
2. Go to Point of Sale > Configuration > Payment Methods.
3. Open HighRiskify POS Crypto.
4. Configure API endpoint, checkout domain, payout wallets, QR fallback, confirmations, and tracking settings where required.
5. Add the payment method to your POS configuration.
6. Close and reopen the POS session.
