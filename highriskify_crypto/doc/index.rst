HighRiskify Crypto
===================

Hosted non-custodial crypto checkout integration for Odoo 18.

Install the module, configure the HighRiskify Crypto payment provider, add merchant payout wallet addresses, and enable the provider for Odoo Website/eCommerce or payment flows.

External services: this module connects to HighRiskify services for checkout session creation, payment status synchronization, callback handling, and operational transaction tracking. See the module README and app description for data handling details.
