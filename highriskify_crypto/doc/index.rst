Long Description
----------------

HighRiskify Crypto is a Cryptocurrency Non-Custodial Crypto Payment Gateway for Odoo Website, Odoo Ecommerce, Odoo Invoicing, and compatible Odoo Subscription payment flows. It supports hosted checkout, QR payments, wallet payments, payment links, crypto invoices, invoice email payment flows, and webhook-synchronized transaction status updates.
